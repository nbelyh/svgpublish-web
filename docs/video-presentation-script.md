
# The SvgPublish web part helps you bring interactive diagrams to SharePoint

You can add this web part to any modern SharePoint page.

Using the file picker, you select an SVG file to display. Typically, the file is exported from a Visio diagram using the SvgPublish tool, but it can also be any other SVG file.

It can be an org chart or practically any other type of diagram. The web part is lightning fast for simple diagrams, making them feel like an integral part of your site. It supports core diagram viewer functions such as zoom and pan. You can also save the current view for optimal display.

The web part supports property display, page navigation, and file navigation, allowing you to build a navigation system on a single page. It also supports a breadcrumb trail, so you always know where you are in the hierarchy and can navigate back and forth.

All features—including pan, zoom, navigation, header, and breadcrumb trail—can be configured through the web part settings. A Full Page mode lets you comfortably view large diagrams with lots of detail.

The web part supports interactive features such as related-item highlighting. You can control colors and styles to match your branding.

You can extend diagrams with custom content such as tooltips, sidebar content, and shape-level content. Custom content can use shape data, so you can display dynamic information based on shape properties. You can also use basic text formatting (Markdown), images, and links in the custom content. Custom scripts are not allowed for security reasons.

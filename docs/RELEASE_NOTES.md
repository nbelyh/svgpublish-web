# &#x1F680; Key Features

## Modern SharePoint Integration

- **Native SharePoint Web Part**: Seamlessly integrates with modern SharePoint pages and sites
- **No Custom Scripts Required**: Works perfectly even when SharePoint has custom scripts disabled
- **Tenant Privacy**: Runs entirely within your SharePoint tenant - no external services or third-party servers
- **AppSource Availability**: Official Microsoft AppSource distribution for easy deployment

## Rich Interactive Experience

- **Pan & Zoom Controls**: Navigate through large diagrams with intuitive controls
- **Shape Selection**: Click on shapes to view detailed information
- **Connection Flow Highlighting**: Visual highlighting of connected shapes and connectors
- **Hover Effects**: Interactive hover highlighting with customizable colors
- **Hyperlink Support**: Follow embedded hyperlinks within your diagrams

## Advanced Visualization Features

- **Layer Controls**: Show/hide diagram layers with search and sorting options
- **Multi-Page Navigation**: Navigate between multiple diagram pages with breadcrumbs
- **Tooltips**: Rich tooltip support with custom content and multiple trigger options
- **Search Functionality**: Find shapes and properties quickly across large diagrams
- **Fullscreen Mode**: View diagrams in fullscreen for detailed analysis

## Flexible Content Display

- **Information Sidebar**: Comprehensive sidebar showing shape properties, links, and custom content
- **Custom Templates**: Support for Markdown-based custom content in tooltips, sidebar, and overlays
- **Property Filtering**: Display specific shape properties based on your needs
- **Responsive Design**: Optimized for desktop, tablet, and mobile viewing

## Touch and Mobile Optimized

- **Touch Gestures**: Configurable touch controls with two-finger zoom options
- **Mobile-Friendly**: Optimized interface for mobile and tablet devices
- **Modifier Key Support**: Optional Ctrl/Shift key requirements to prevent accidental zooming

# &#x1F3AF; Perfect For

- **Business Process Documentation**: Interactive workflow and process diagrams
- **Organizational Charts**: Company hierarchies with detailed employee information
- **Technical Documentation**: Network diagrams, database schemas, and system architecture
- **Facility Management**: Floor plans with room and equipment details
- **Project Planning**: Gantt charts and project timelines with interactive elements

# &#x1F527; Easy Configuration

The web part provides an intuitive property panel organized into logical groups:

- **Source File**: Simple file picker for SharePoint-stored SVG files
- **Appearance**: Pan, zoom, and display settings
- **Highlighting & Selection**: Customizable colors and effects
- **Tooltips & Content**: Rich content configuration options
- **Sidebar & Navigation**: Information display and search settings

# &#x1F4F1; Installation

1. Get the web part from [Microsoft AppSource](https://appsource.microsoft.com/en-us/product/office/WA200009144)
2. Add to your SharePoint environment
3. Edit any SharePoint page and search for "SVG Publish"
4. Add the web part and configure with your Visio-exported SVG files

More details: [SVG Publish SharePoint Web Part](https://unmanagedvisio.com/products/svg-publish/svg-publish-sharepoint-web-part/)

# &#x1F517; Companion Tool

This web part is designed to work with SVG files exported using the **SVG Publish** add-in for Microsoft Visio. While it can display any SVG file, the full interactive features are available when using properly exported diagrams.

Learn more about SVG Publish: <https://unmanagedvisio.com/products/svg-publish/>

# &#x1F6E1; Privacy & Security

- **Tenant Isolation**: All diagram processing happens within your SharePoint tenant
- **No External Dependencies**: No calls to external services or third-party servers
- **SharePoint Permissions**: Respects existing SharePoint file permissions and access controls
- **Secure by Design**: Built with SharePoint Online security best practices
